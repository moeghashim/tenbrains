# Wayfinder Voice

## Purpose

Ten Brains uses controlled language because a decision ledger must stay clear under pressure. Each map artifact should state one concrete claim, question, or action so You and Wayfinder can review evidence, see what is still fog, and decide what to build or kill without decoding vague prose.

## Surface rules

This is an ASD-STE100-inspired controlled language. It is not full STE-100 compliance, and it does not use a restricted dictionary.

### Map artifacts: hard rules

Apply these rules to decision card titles, ticket titles and summaries, fog questions, evidence statements, Discovery Spec text, empty states, buttons, and labels.

- Use a maximum of 20 words per sentence.
- Put one idea in each sentence.
- Use active voice.
- Use imperative mood for ticket titles and actions.
- Make each fog card exactly one question.
- End each fog question with `?`.
- Write decision titles as declarative commitments.
- Use verb-first decision titles where it sounds natural.
- Remove hedging filler: maybe, perhaps, we think, sort of.
- Remove marketing adjectives.
- Use the controlled glossary names.
- Do not introduce actors beyond You and Wayfinder.
- Use `ticket` for actionable work.
- Do not use task, card, or work item in product copy.

### Grilling and chat transcript: soft rules

Apply these rules to Wayfinder conversational turns and transcript demo copy.

- Natural language is allowed.
- Prefer short sentences.
- Ask one question per Wayfinder turn.
- Remove hedging filler from Wayfinder turns: maybe, perhaps, we think, sort of.
- Keep You turns natural. Contractions and spoken hedging in You turns are demo data for Wayfinder to grill.
- Quote evidence verbatim. Never edit text inside quotation marks.
- Do not use exclamation marks.
- Keep the two actors clear: You and Wayfinder.

## Controlled glossary

| Concept | Canonical name | Banned synonyms in copy |
| --- | --- | --- |
| Product | Ten Brains | User Wayfinder, Wayfinder app, decision app |
| AI actor | Wayfinder | assistant, bot, AI agent, model, co-pilot |
| Human actor | You | user account, member, teammate, collaborator, participant |
| Desired outcome | Destination | goal, north star, objective outcome, mission |
| Actionable work area | Open Frontier | frontier, backlog, kanban, open tasks, work queue |
| Unresolved questions | Fog of War | unknowns, risks, doubts, ambiguity board |
| Unresolved question shorthand | fog | fuzziness, uncertainty, murk, grey area |
| Evidence-backed conclusion | Closed Decision | decision, conclusion, resolved item, answer |
| Actionable unit | ticket | task, card, work item, issue, to-do |
| Supporting proof | evidence | proof point, insight, note, finding |
| Product exploration unit | discovery | project, workspace, initiative, board |
| Focused interaction | session | meeting, interview call, workshop, chat room |
| Ticket types | Grilling, Research, Prototype, Synthesis | interview, call, analysis, experiment, session (as a ticket-type label) |
| Work mode | You | owner, assignee, member, participant |
| Work mode | Wayfinder | assistant, bot, AI, model |
| Work mode | You + Wayfinder | team, collaboration mode, shared owner, pair |

## Examples

| Before | After | Why |
| --- | --- | --- |
| Maybe users might want more automation later. | Users need review before automation. | Removes hedging and states a decision. |
| Research task: look into competitor onboarding. | Research competitor onboarding patterns. | Uses imperative mood and `ticket` language. |
| What are all the risks and open questions around permissions? | What permission feels safe by default? | Makes one fog card one question. |
| Wayfinder found a really powerful insight from the interviews. | Evidence shows read-only suggestions earn trust first. | Removes marketing adjectives and names the evidence claim. |

## Acceptance checklist

- [ ] Each map artifact sentence has 20 words or fewer.
- [ ] Each map artifact sentence states one idea.
- [ ] Ticket titles and action labels use imperative mood.
- [ ] Each fog card has one question and ends with `?`.
- [ ] Decision titles state declarative commitments.
- [ ] Hedging filler is absent.
- [ ] Marketing adjectives are absent.
- [ ] The glossary uses one canonical name per concept.
- [ ] The only product actors are You and Wayfinder.
- [ ] Actionable work is called a ticket.
- [ ] Chat turns use no exclamation marks.
- [ ] Wayfinder asks no more than one question per turn.
